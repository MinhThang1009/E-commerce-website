\textbf{\large{Abstract}}
\end{center}
\addcontentsline{toc}{chapter}{Abstract}

\begin{small}

E-commerce is rapidly growing in Vietnam; however, most existing platforms still lack intelligent product advisory capabilities, heavily relying on users to search and filter products on their own. This thesis presents the development of \textbf{TechStore}, a full-stack e-commerce website specializing in technology products, integrated with an AI Chatbot using the RAG (Retrieval-Augmented Generation) technique for real-time product consultation.

The system is built on a Modular Monolith architecture with 17 independent backend modules communicating via an Event-Driven pattern. The frontend follows a Feature-Based design with 13 isolated features. The AI Chatbot is the core component, implementing a RAG pipeline that combines Hybrid Search (cosine similarity and BM25 keyword scoring) with an OpenAI-compatible large language model to generate natural Vietnamese responses. The embedding pipeline adopts a chain-fallback strategy across three providers (Jina v3, HuggingFace multilingual-e5-large-instruct, HuggingFace multilingual-e5-large), producing 1024-dimensional vectors.

The system provides comprehensive e-commerce functionalities including product and category management, shopping cart for both guest and authenticated users, order placement with online payment via MoMo and VNPay, product reviews, inventory management with race condition prevention, and a full-featured administration dashboard. The test suite comprises 5,480 test cases distributed across 5 layers (unit, integration, API HTTP, E2E, and component tests), achieving 100\% line coverage and 99.81\% branch coverage at the unit test level.

\vspace*{0.5cm}
\textbf{Keywords}: E-commerce, RAG (Retrieval-Augmented Generation), AI Chatbot, Modular Monolith, Hybrid Vector Search.

\end{small}
