\section*{Kết quả đạt được}
\addcontentsline{toc}{section}{Kết quả đạt được}

Khóa luận đã hoàn thành xây dựng hệ thống \textbf{TechStore} --- website thương mại điện tử tích hợp AI Chatbot RAG. Các kết quả cụ thể đạt được bao gồm:

\textbf{Về kiến trúc và backend:} Hệ thống được xây dựng với kiến trúc Modular Monolith gồm 19 modules độc lập, áp dụng Dependency Injection pattern và EventBus pub/sub nội bộ. Schema cơ sở dữ liệu 35 bảng với 72 migrations được quản lý chặt chẽ qua Sequelize CLI. UnitOfWork với SELECT FOR UPDATE đảm bảo tính nhất quán khi xử lý đồng thời (đặt hàng, đổi điểm loyalty).

\textbf{Về AI Chatbot RAG:} Pipeline RAG 6 bước được cài đặt hoàn chỉnh với Hybrid Search kết hợp cosine similarity và BM25-inspired keyword search trên vector 1024 chiều. Smart product filtering giảm 60--70\% tokens gửi lên LLM. Chuỗi fallback embedding (Jina v3 → HuggingFace) đảm bảo hoạt động ngay cả khi provider chính không khả dụng.

\textbf{Về tính năng:} Hệ thống cung cấp đầy đủ vòng đời TMĐT: xác thực JWT + Google OAuth, giỏ hàng guest/authenticated với merge, đặt hàng với SELECT FOR UPDATE, thanh toán MoMo/VNPay qua IPN webhook, hệ thống loyalty points, đánh giá sản phẩm và trang quản trị toàn diện với analytics.

\textbf{Về chất lượng phần mềm:} Hệ thống đạt 5.694 test cases với coverage 99\% (statements, functions, lines) và 97\% (branches). CI/CD được thiết lập với GitHub Actions, Husky pre-commit hooks (secret scanning, architecture audit, lint-staged) và kiểm tra bundle size.

\textbf{Về giao diện:} Frontend React 18 với 14 features, hỗ trợ dark mode, đa ngôn ngữ (Vi/En), responsive trên mọi thiết bị. Chat widget floating với Liquid Glass design system, có thể kéo và resize.

\section*{Hạn chế}
\addcontentsline{toc}{section}{Hạn chế}

Bên cạnh các kết quả đạt được, hệ thống vẫn còn một số hạn chế cần cải thiện:

\textbf{Về AI Chatbot:} Conversation history lưu in-memory (reset khi restart server), chưa persist bền vững. Chưa có cơ chế học từ phản hồi người dùng để cải thiện độ chính xác theo thời gian.

\textbf{Về hiệu năng:} Vector store lưu trên disk dạng JSON, phù hợp với quy mô hiện tại nhưng cần chuyển sang vector database chuyên dụng (Qdrant, Pinecone) khi số lượng sản phẩm lớn hơn.

\textbf{Về thanh toán:} Chưa hỗ trợ hoàn tiền tự động qua MoMo. Chưa tích hợp thẻ tín dụng quốc tế.

\textbf{Về triển khai:} Hệ thống hiện chạy trên môi trường local, chưa có hướng dẫn triển khai production với load balancer, CDN và database replication.

\section*{Hướng phát triển}
\addcontentsline{toc}{section}{Hướng phát triển}

Dựa trên nền tảng đã xây dựng, các hướng phát triển tiếp theo bao gồm:

\textbf{Nâng cấp AI Chatbot:} Tích hợp vector database (Qdrant) để xử lý catalog lớn hơn; implement conversation memory bền vững với Redis; fine-tune LLM với dữ liệu đặc thù của domain thiết bị công nghệ; bổ sung multimodal (tìm kiếm bằng ảnh sản phẩm).

\textbf{Mở rộng tính năng:} Phát triển ứng dụng mobile (React Native) để tận dụng lại API hiện có; bổ sung tính năng so sánh sản phẩm (so sánh song song thông số kỹ thuật); tích hợp thêm phương thức thanh toán (Stripe, ZaloPay).

\textbf{Cải thiện hạ tầng:} Tách vector store thành microservice độc lập; implement Redis Cluster cho high availability; thiết lập monitoring với Datadog/Prometheus; container hóa với Docker và orchestration với Kubernetes.

\textbf{Phân tích dữ liệu:} Xây dựng recommendation engine dựa trên lịch sử mua hàng và hành vi người dùng; A/B testing cho giao diện và pricing; báo cáo phân tích nâng cao với cohort analysis và funnel visualization.
