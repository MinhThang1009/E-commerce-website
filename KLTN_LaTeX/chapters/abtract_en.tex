\textbf{\large{Abstract}}

\addcontentsline{toc}{chapter}{Abstract}

\begin{small}

E-commerce in Vietnam is growing rapidly at an average rate of 20--25\% annually. However, providing automated, accurate, and timely product advisory services remains a significant challenge for current e-commerce platforms. This thesis presents the development of \textbf{TechStore} --- a fullstack e-commerce website specializing in technology devices (laptops, smartphones, tablets, smartwatches), integrated with an AI Chatbot using RAG (Retrieval-Augmented Generation) technique for real-time product consultation.

The system is built with a \textbf{Modular Monolith} architecture, featuring a backend of \textbf{19 independent modules} using Node.js 20 + Express 4 + Sequelize 6 + MySQL 8, and a frontend of \textbf{14 features} with React 18 + TypeScript + Vite 5. The backend employs Dependency Injection pattern, an in-process EventBus for pub/sub communication, and UnitOfWork with SELECT FOR UPDATE to ensure data consistency in concurrent scenarios.

The AI Chatbot system implements a 6-step RAG pipeline: rate limiting, cache verification, smart product filtering, context augmentation, LLM generation (via OpenAI-compatible API), and response caching. The vector store maintains 1024-dimensional embeddings per product, using Hybrid Search combining cosine similarity (semantic) and BM25-inspired keyword search. The embedding fallback chain: Jina v3 → HuggingFace multilingual-e5-large-instruct → multilingual-e5-large.

Key features include: JWT authentication (15-minute access token + 30-day refresh token) with Google OAuth 2.0; MoMo and VNPay payment integration via IPN webhook; race condition-safe inventory management; loyalty points program; and bilingual support (Vietnamese/English). The MySQL 8 database consists of \textbf{35 tables} and \textbf{72 migrations} ensuring schema consistency.

The system achieves \textbf{5,694 test cases} with 99\% coverage (unit tests), including unit, integration, API HTTP, and E2E tests. CI/CD is configured with GitHub Actions, Husky pre-commit hooks, and strict ESLint mode.

\vspace*{0.5cm}
\textbf{Keywords}: E-commerce, RAG, AI Chatbot, Node.js, React, MySQL, Modular Monolith, Vector Search, MoMo, VNPay.

\end{small}
