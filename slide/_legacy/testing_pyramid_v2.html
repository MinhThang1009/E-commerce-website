⚠️ Lưu ý trung thực khi bảo vệ: Hình tháp xếp theo cấp độ phạm vi (scope) — không theo số lượng tuyệt đối. Vì vậy tầng API HTTP (700 test) thực tế đông hơn Integration (184 test): API test phủ toàn bộ endpoint × nhiều case (happy path, validate, phân quyền, edge), còn Integration chỉ kiểm tích hợp service↔DB ở mức module. Thứ bậc tầng vẫn đúng pyramid; chỉ phân bố số lượng nghiêng về API do app API-centric.
Cách đọc: càng lên cao → test càng chậm, đắt, ít nhưng phủ phạm vi rộng hơn (E2E chạy nguyên luồng user); càng xuống đáy → test càng nhanh, rẻ, nhiều và cô lập (Unit kiểm 1 hàm với mock). Chiến lược: dồn số lượng vào đáy để feedback nhanh mỗi commit, giữ đỉnh mỏng vì E2E giòn và tốn thời gian.
