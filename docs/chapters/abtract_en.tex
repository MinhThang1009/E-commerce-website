\textbf{\large{Abstract}}
\end{center}
\addcontentsline{toc}{chapter}{Abstract}

\begin{small}

Vietnam's e-commerce market reached USD 32 billion in 2024, with technology products accounting for the largest segment, yet most existing platforms lack natural language product advisory capabilities. Consumers must filter products through static criteria despite expressing their needs in multi-constraint natural language, while Retrieval-Augmented Generation (RAG) has been proven effective but has not been fully implemented for Vietnamese with language-specific challenges such as brand abbreviation normalization and real-time catalog synchronization.

This project proposes and implements a RAG Hybrid architecture combining semantic search (cosine similarity) and keyword search (BM25-inspired scoring) as complementary mechanisms, integrated within the TechStore e-commerce system built on a Modular Monolith (17 backend modules) and Feature-Based (13 frontend features) architecture. The RAG pipeline incorporates Vietnamese brand abbreviation normalization, automatic vector store synchronization on catalog changes, and a multi-tier fallback mechanism to ensure chatbot availability.

Evaluation across 20 real-world scenarios in 5 categories demonstrates that the chatbot achieves approximately 90\% accuracy on semantic queries, successfully handles specific model name lookups via Hybrid Search, normalizes common Vietnamese abbreviations, and rejects 100\% of out-of-scope queries in under 10ms. Average response time is approximately 10 seconds (ranging 6--22 seconds depending on the configured LLM model and response length). The system is validated by approximately 7,578 test cases across 5 testing tiers, achieving 100\% line coverage at the unit level.

Results confirm the feasibility of the RAG Hybrid architecture for Vietnamese e-commerce product advisory and contribute concrete technical solutions for language-specific challenges, providing a reference foundation for AI-powered product consultation applications in Vietnam.

\vspace*{0.5cm}
\textbf{Keywords}: E-commerce, RAG (Retrieval-Augmented Generation), AI Chatbot, Modular Monolith, Hybrid Vector Search.

\end{small}
