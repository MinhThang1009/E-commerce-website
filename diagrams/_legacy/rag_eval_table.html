Tìm kiếm ngữ nghĩa "sinh viên cần laptop nhẹ, pin lâu, dưới 20 triệu" Tốt Hybrid search (semantic cosine + keyword) xử lý tốt query mô tả đa tiêu chí
Tên model cụ thể "iPhone 17 giá bao nhiêu?" Tốt Hybrid search + trích số model (version extraction) bắt chính xác tên/đời máy
Viết tắt / sai chính tả "ip17pm giá bao nhiêu" · "iphone 17 gia bao nhieu" Tốt expandAbbreviations chuẩn hóa (ip→iPhone, pm→Pro Max, không dấu→có dấu)
Câu hỏi so sánh "so sánh iPhone 17 Pro và Samsung Galaxy S25 Ultra" Khá LLM cần đủ context cả 2 sản phẩm để so sánh; khi LLM DOWN chỉ liệt kê
Ngoài phạm vi "thời tiết hôm nay thế nào" · "bóng đá Samsung S25" Tốt Off-topic gate (intent == off_topic) từ chối nhanh, không gọi retrieval/LLM
Thang đánh giá: Tốt = PASS ở cả LLM UP và LLM DOWN · Khá = chỉ đạt đầy đủ khi LLM UP (fallback keyword bị giới hạn). Nguồn: RAG_CHATBOT_PIPELINE.md §4 (53 edge cases) và PIPELINE_TRACE_EXAMPLES.md (22 path trace).
